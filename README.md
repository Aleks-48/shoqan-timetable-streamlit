# Shoqan Day

Текущий формат: предложение идеи университету с работающим MVP. Проведение пилота не требуется для подготовки этого пакета. [Анализ и план внедрения](docs/university-proposal.md).

Студенческий MVP для идеятона: ИИ выделяет требования из текста задания, студент подтверждает срок и время подготовки, планировщик предлагает свободные блоки вокруг занятий. Три основных экрана: Сегодня, Мой план, Настройки. Расписание, темы и импорт остаются вспомогательными инструментами.

План строится на 14 дней, исключает прошедшее время и занятия выбранной группы, оставляет 10 минут между блоками и занятиями. Блоки подготовки — от 15 до 50 минут; при необходимости длительность делится так, чтобы не оставлять незапланированный короткий хвост. Для расписания из конкретных дат пустые дни считаются свободными только внутри явно заданного интервала покрытия (`coverage_start`, `coverage_end`); без него используются только даты с записями, а остальные даты неизвестны. Невместившиеся задания показываются с причиной; личные дела вне расписания не учитываются. Разбор ИИ требует серверного ключа Gemini. Автоматические тесты интеграции используют имитацию ответа. [Анализ продукта и рынка](docs/product-research-2026.md).

## Запуск

Python 3.12 (проверенная версия окружения).

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Streamlit Community Cloud: репозиторий Aleks-48/shoqan-timetable-streamlit, app.py. Для расписания API-ключи не нужны. ИИ-импорт требует GEMINI_API_KEY в Streamlit Secrets: [инструкция](docs/ai-setup.md). Не храните секреты в Git.

## Данные

Встроенный набор вымышленный и явно обозначен как демо. Для университетского внедрения нужен разрешённый источник расписания и ответственный за обновления. Импорт выполняется только в сессии пользователя и не меняет данные других посетителей. Группа и тема записываются в URL для закладок. В Настройки → Данные можно включить сохранение расписания, задач и настроек в этом браузере. Полная JSON-копия переносит их на другое устройство. Без включения сохранения данные действуют в сессии. Аккаунтов и облачной синхронизации нет. Встроен также снимок 23 занятий ИСР-242уск за 28.09–03.10.2026 из присланных пользователем скриншотов. Он не повторяется на других неделях и не обновляется автоматически.

CSV: обязательные group,start_time,end_time,subject,teacher,room и один из weekday/date. Для каждой строки заполнить либо русский день недели, либо дату YYYY-MM-DD. Время ЧЧ:ММ; конец строго позже начала. Для снимка с подтверждённым периодом добавьте в заголовок `coverage_start,coverage_end` и укажите одинаковые границы YYYY-MM-DD в каждой строке. Без этих метаданных даты без строк расписания неизвестны; планировщик использует только даты, где есть занятия. Метаданные покрытия допускаются только для расписания по точным датам, не для weekday. teacher/room можно оставить пустыми. До 2 МБ и 10 000 строк. UTF-8 / Windows-1251, запятая / точка с запятой. Номера аудиторий с ведущими нулями сохраняются. Файл с ошибками отклоняется полностью, строки не теряются молча. Полные дубликаты отклоняются.

weekday повторяется еженедельно без учёта каникул. Для периода обучения используйте точные date. Проверка пересечений охватывает одну группу на выбранной неделе, а не распределение кабинетов всего университета. ICS содержит только выбранную неделю в UTC с преобразованием из Asia/Almaty; автоматической синхронизации и push-уведомлений нет.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты покрывают некорректные времена и даты, пустые файлы, дубликаты, кодировку, пересечения, ICS, пустую неделю, темы, таблицу, поиск и изоляцию задач. Проверка интерфейса: светлая/тёмная темы, карточки дня, затем CSV-импорт и экспорт перед демонстрацией.
