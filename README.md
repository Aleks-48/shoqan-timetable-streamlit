# Shoqan Day

Студенческий MVP расписания для идеятона: ближайшая пара, день и неделя, поиск по группе/преподавателю/аудитории, три темы, импорт CSV с предпросмотром, проверка пересечений внутри группы, экспорт недели ICS/CSV и учебные задачи с JSON-копией.

## Запуск

Python 3.12 (проверенная версия окружения).

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Streamlit Community Cloud: репозиторий Aleks-48/shoqan-timetable-streamlit, app.py. Для расписания API-ключи не нужны. ИИ-импорт требует GEMINI_API_KEY в Streamlit Secrets: [инструкция](docs/ai-setup.md). Не храните секреты в Git.

## Данные

Встроенный набор вымышленный и явно обозначен как демо. Для настоящего пилота нужен разрешённый источник расписания и ответственный за обновления. Импорт выполняется только в сессии пользователя и не меняет данные других посетителей. Группа и тема записываются в URL для закладок. Задачи действуют в сессии, доступны выгрузка и восстановление JSON; постоянной базы и аккаунтов пока нет.

CSV: обязательные group,start_time,end_time,subject,teacher,room и один из weekday/date. Для каждой строки заполнить либо русский день недели, либо дату YYYY-MM-DD. Время ЧЧ:ММ; конец строго позже начала. teacher/room можно оставить пустыми. До 2 МБ и 10 000 строк. UTF-8 / Windows-1251, запятая / точка с запятой. Номера аудиторий с ведущими нулями сохраняются. Файл с ошибками отклоняется полностью, строки не теряются молча. Полные дубликаты отклоняются.

weekday повторяется еженедельно без учёта каникул. Для периода обучения используйте точные date. Проверка пересечений охватывает одну группу на выбранной неделе, а не распределение кабинетов всего университета. ICS содержит только выбранную неделю в UTC с преобразованием из Asia/Almaty; автоматической синхронизации и push-уведомлений нет.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты покрывают некорректные времена и даты, пустые файлы, дубликаты, кодировку, пересечения, ICS, пустую неделю, темы, таблицу, поиск и изоляцию задач. Проверка интерфейса: светлая/тёмная темы, карточки дня, затем CSV-импорт и экспорт перед пилотом.
