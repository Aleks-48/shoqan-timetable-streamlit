# Shoqan Day

Текущий формат: предложение идеи университету с работающим MVP. Проведение пилота не требуется для подготовки этого пакета. [Анализ и план внедрения](docs/university-proposal.md).

Студенческий MVP для идеятона: календарь на неделю, задания и персональный план подготовки. Расписание, темы и импорт остаются вспомогательными инструментами.

В разделе «Мой план» можно вставить текст преподавателя. Настроенный Gemini предлагает предмет, явные требования, однозначный срок и этапы; студент может всё изменить. Предпросмотр блоков не меняет календарь. «Отмена» отбрасывает черновик, а «Подтвердить и добавить» сохраняет задание и рассчитанные блоки. Каждый блок отмечается выполненным отдельно. Без ключа Gemini доступно ручное добавление.

План строится минимум на 14 дней и расширяется до дедлайна, максимум до 30 дней, исключает прошедшее время и занятия выбранной группы, оставляет 10 минут между блоками и занятиями. Блоки подготовки — от 15 до 50 минут; при необходимости длительность делится так, чтобы не оставлять незапланированный короткий хвост. Для расписания из конкретных дат пустые дни считаются свободными только внутри явно заданного интервала покрытия (`coverage_start`, `coverage_end`); без него используются только даты с записями, а остальные даты неизвестны. Невместившиеся задания показываются с причиной; личные дела вне расписания не учитываются. Разбор ИИ требует серверного ключа Gemini. Автоматические тесты интеграции используют имитацию ответа. [Анализ продукта и рынка](docs/product-research-2026.md).

## Группы и автоплан

По умолчанию приложение показывает один явно маркированный синтетический демо-набор. Оно не выдумывает расписания других групп и не получает официальные данные автоматически. В разделе «Настройки → Данные» можно импортировать CSV с расписаниями до 10 реальных групп; группы сохраняются как отдельные профили с собственным источником и покрытием. Импорт с тем же названием группы заменяет только расписание, сохраняя её задания. План другой группы при переключении не показывается и не изменяется. Реальный снимок ИСР-242уск за 28 сентября — 3 октября 2026 года остаётся отдельным ручным источником без автоматического обновления.

После AI-разбора студент редактирует название, предмет, срок, требования и этапы, а также строки чернового плана: дату, время начала и длительность блока. Планировщик проверяет покрытие, дедлайн, дневной лимит, пары и десятиминутные переходы, другие блоки и взаимные пересечения. Неразмещённые минуты показываются явно. Пока студент не подтвердит задание, оно и предложенные блоки не сохраняются. Пары не редактируются и не сдвигаются планировщиком.

## Запуск

Python 3.12 (проверенная версия окружения).

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

For a screenshot review, start the loopback-only server with `.\run-local.ps1 -PythonPath 'C:\path\to\python.exe'` and open `http://127.0.0.1:8501` in a browser. Use a different `-Port` if 8501 is already occupied. The script sends no usage telemetry.

Streamlit Community Cloud: репозиторий Aleks-48/shoqan-timetable-streamlit, app.py. Для расписания API-ключи не нужны. ИИ-импорт требует GEMINI_API_KEY в Streamlit Secrets: [инструкция](docs/ai-setup.md). Не храните секреты в Git.

## Данные

`data/isr242_2026-09-28.csv` — неофициальный архивный снимок расписания ISR-242, вручную перенесённый из пользовательских скриншотов. Его покрытие завершилось 3 октября 2026 года; это не актуальное расписание и автоматического обновления нет. Проверяйте текущие занятия по разрешённому действующему источнику.

Лимит импорта — до 10 различных групп суммарно во всех загруженных CSV. Это вместимость, а не десять подготовленных расписаний: в репозитории есть один синтетический демо-набор и один архивный снимок.

Встроенный набор вымышленный и явно обозначен как демо. Для университетского внедрения нужен разрешённый источник расписания и ответственный за обновления. Импорт выполняется только в сессии пользователя и не меняет данные других посетителей. Группа и тема записываются в URL для закладок. В Настройки → Данные можно включить сохранение расписания, задач и настроек в этом браузере. Полная JSON-копия переносит их на другое устройство. Без включения сохранения данные действуют в сессии. Аккаунтов и облачной синхронизации нет. Встроен также снимок 23 занятий ИСР-242уск за 28.09—03.10.2026 из присланных пользователем скриншотов. Он не повторяется на других неделях и не обновляется автоматически.

CSV: обязательные group,start_time,end_time,subject,teacher,room и один из weekday/date. Для каждой строки заполнить либо русский день недели, либо дату YYYY-MM-DD. Время ЧЧ:ММ; конец строго позже начала. Для снимка с подтверждённым периодом добавьте в заголовок `coverage_start,coverage_end` и укажите одинаковые границы YYYY-MM-DD в каждой строке. Без этих метаданных даты без строк расписания неизвестны; планировщик использует только даты, где есть занятия. Метаданные покрытия допускаются только для расписания по точным датам, не для weekday. teacher/room можно оставить пустыми. До 2 МБ и 10 000 строк. UTF-8 / Windows-1251, запятая / точка с запятой. Номера аудиторий с ведущими нулями сохраняются. Файл с ошибками отклоняется полностью, строки не теряются молча. Полные дубликаты отклоняются.

weekday повторяется еженедельно без учёта каникул. Для периода обучения используйте точные date. Проверка пересечений охватывает одну группу на выбранной неделе, а не распределение кабинетов всего университета. ICS содержит только выбранную неделю в UTC с преобразованием из Asia/Almaty; автоматической синхронизации и push-уведомлений нет.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты покрывают некорректные времена и даты, пустые файлы, дубликаты, кодировку, пересечения, ICS, пустую неделю, темы, таблицу, поиск, отмену черновика, конкурирующие задания, восстановление блоков и прогресс. `node tests/storage_test.mjs` проверяет локальное сохранение, конфликт вкладок, отключение и ошибки localStorage.
