# Расписание Shoqan — прототип на Streamlit

Минимальное приложение для просмотра расписания по группе: занятия на сегодня, неделя и поиск. В проект включены только демонстрационные строки; они вымышлены и не являются официальными данными Shoqan University.

## Запуск на Windows

1. Установите Python 3.10 или новее.
2. Распакуйте/откройте эту папку в терминале.
3. Выполните команды:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

Если PowerShell блокирует активацию окружения, можно обойтись без активации:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Streamlit покажет локальный адрес приложения в терминале и откроет его в браузере.

## Загрузка своего расписания

В боковой панели приложения загрузите CSV или скачайте шаблон. Поддерживаются:

- `weekday` — русский день недели для повторяющегося недельного расписания; либо
- `date` — конкретная дата в формате `YYYY-MM-DD`;
- обязательные колонки: `group`, `start_time`, `end_time`, `subject`, `teacher`, `room`.

Времена указываются как `09:00`. Данные из загруженного файла действуют в текущем сеансе приложения и не сохраняются в базу.

## Публикация через GitHub и Streamlit Community Cloud

1. Создайте новый GitHub-репозиторий.
2. Загрузите в него содержимое этой папки, включая `app.py`, `requirements.txt` и `data/schedule_demo.csv`.
3. На Streamlit Community Cloud выберите этот репозиторий и файл `app.py` как точку входа.

Для первого прототипа не нужны API-ключи. Не добавляйте пароли и ключи в репозиторий. Перед показом студентам замените демонстрационный CSV реальным расписанием, полученным с разрешённого университетского источника.
