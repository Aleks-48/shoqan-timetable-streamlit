# Протокол первого пилота

План, а не полученные результаты. 20 добровольцев одной группы, 2 недели. Использовать обезличенные задания с разрешения авторов. Персональные сообщения и сведения о студентах в ИИ не отправлять.

1. Подготовить 20 заданий: явная дата, относительная дата, отсутствующий срок, несколько результатов сдачи, уточнение требований, казахский текст. До запуска вручную записать правильные требования, точную дату либо отсутствие определённой даты.
2. Для каждого ответа отметить: цитата совпала с оригиналом; требования не потеряны; дата верна либо запрошено уточнение; модель не добавила обязательных требований. Предложения по подготовке оценивать отдельно от требований преподавателя.
3. Дать сопоставимые задания для ручного переноса и Shoqan Day. Половина участников начинает с ручного способа, половина с приложения. Засекать время до проверенного плана, а не до первого ответа модели.
4. Записать ошибки, исправления, отказы ИИ, время, повторное использование во вторую неделю. Не сохранять имена: только добровольный код участника.
5. Перед началом утвердить критерии: ноль пересечений с занятиями в подтверждённом плане; ни одна ошибочная дата не проходит без проверки; медианное время меньше ручного способа. Эти критерии не являются обещанием результата.
