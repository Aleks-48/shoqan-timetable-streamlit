# Что взято из расписания университета

Источник: https://timetable.kgu.kz/ и четыре скриншота пользователя от 29.09.2026. Открытая страница показывает вход; страница студента требует авторизации. Закрытые данные не выгружались, автоматическая синхронизация не заявляется.

Реализовано:
- Демонстрационные занятия и CSV-шаблон по 50 минут. Импортированные интервалы сохраняются без принудительного округления.
- Справочная сетка звонков: 08:30–09:20, 09:30–10:20, 10:30–11:20, 11:30–12:20, 12:30–13:20; затем 13:40–14:30 и каждый час до 20:40–21:30. Основание — скриншоты, не официальный API.
- Перерывы и окна между занятиями текущего дня. Окном считается промежуток от 50 минут. Пересекающиеся интервалы объединяются при расчёте свободного времени.
- Корпус и тип занятия как необязательные поля building/lesson_type. Сохраняются в CSV, карточках, поиске, таблице и календаре.
- Быстрые переходы по неделям, ссылка на официальный источник, сохранение всего расписания CSV.

Не переносим: логин пользователя, списки студентов, идентификаторы конференций, служебные коды и счётчики. Не копируем закрытое личное расписание в общедоступное демо. Сокращения типов сохраняем как в источнике, без неподтверждённых расшифровок.

Повторные занятия одного предмета остаются отдельными строками, поскольку между ними есть перерыв. Авторизация университета не запрашивается нашим приложением. Для своего расписания пользователь может импортировать разрешённый CSV или распознать файл после подключения Gemini.
