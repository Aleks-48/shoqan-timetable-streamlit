# Подключение Gemini

1. Создайте API-ключ в https://aistudio.google.com/apikey. Для бесплатного режима используйте проект без подключённого биллинга. Доступность и квоты зависят от аккаунта и региона.
2. Streamlit Community Cloud → Manage app → Settings → Secrets:

```toml
GEMINI_API_KEY = "ваш ключ"
GEMINI_MODEL = "gemini-3.8-flash"
```

3. Сохраните, дождитесь перезапуска. Вкладка «ИИ-импорт»: загрузите разрешённый PNG/JPG/PDF до 4 МБ, подтвердите отправку Google, нажмите распознавание.
4. Сверьте строки с оригиналом, исправьте ошибки, подтвердите замену. До применения действующее расписание не меняется. Скачайте CSV для сохранения между сессиями.

Ключ не включается в репозиторий, URL и сообщения об ошибках. Автоматических повторов и переключения модели нет. Защита приложения: 30 секунд между запросами сессии и 100 запросов в сутки на процесс сервера. Счётчик сбрасывается при перезапуске; это не платёжный лимит. Бесплатность обеспечивается настройками проекта Google, не кодом приложения.

Бесплатный тариф Google может использовать переданные данные для улучшения продуктов. Не загружайте списки студентов, оценки и конфиденциальные документы. Согласие показывается перед отправкой.

Проверки кода используют имитацию API: настоящий запрос необходимо проверить после добавления ключа на одной вымышленной таблице. Качество распознавания не измерено. Аккаунты, уведомления и синхронизация между устройствами ещё не реализованы.

Документация: https://ai.google.dev/gemini-api/docs/pricing и https://ai.google.dev/gemini-api/docs/generate-content/structured-output.
