# Проверка Gemini 29.09.2026

На опубликованном сайте подтверждена модель `gemini-3.8-flash`. Запросы доходили до API, но возвращали HTTP 503. Это временная недоступность сервиса; сам этот код не доказывает неправильный ключ или исчерпание квоты. Первоначальный HTTP 400 перестал воспроизводиться после перехода на `responseMimeType` и `responseJsonSchema`.

Приложение раньше не повторяло временно отклонённые запросы. Добавлены максимум три попытки с растущей паузой и небольшим случайным смещением. Первые две используют настроенную модель; третья после HTTP 502/503/504 использует `gemini-3.5-flash-lite`. При HTTP 400/401/403/404/429 повторов и переключения нет. Никакого включения биллинга или замены ключа не выполнялось.

После публикации исправления живой запрос на вымышленном тексте успешно вернул точную цитату, дату 02.10.2026 и этапы: ER-диаграмма, пять SQL-запросов, отчёт. Это проверка работоспособности одного сценария, не исследование точности модели. Успешный ответ не фиксирует, какая именно из попыток сработала, поэтому утверждать, что ответила исключительно резервная модель, нельзя.

Проверки: 37 автоматических тестов; отдельно проверены успешный повтор, ограничение попыток, переход на резервную модель с сохранением исходного запроса и отсутствие повторов при ошибке ключа/квоты.

Источники: [ошибки Gemini](https://ai.google.dev/gemini-api/docs/api-errors), [стратегия повторов](https://ai.google.dev/gemini-api/docs/troubleshooting), [тарифы моделей](https://ai.google.dev/gemini-api/docs/pricing). Бесплатность зависит от настроек проекта Google и доступной квоты.
