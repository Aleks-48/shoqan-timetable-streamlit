# MVP: проверка перед пилотом, 29.09.2026

Объём версии: расписание, разбор текстового задания ИИ, подтверждение требований, план подготовки. Три основных раздела. Сохранение на личном устройстве включается явно в Настройки → Данные. После полной перезагрузки восстановлены группа ИСР-242уск и контрольное задание. Для другого устройства используется полная JSON-копия.

## Проверено

- 42 Python-теста: CSV, даты, конфликты, 50-минутные занятия, ICS, планирование, изоляция сессий, темы, изменение задания, подключение снимка ИСР-242уск, валидация полной копии, повторы и ошибки ИИ.
- JavaScript-проверки: чтение, запись, отключение сохранения, конфликт двух вкладок, повреждённая копия, отказ localStorage. Команда `node tests/storage_test.mjs`.
- Ручной браузерный сценарий: включение сохранения, применение ИСР-242уск, добавление задания, полная перезагрузка, восстановление расписания и задания.
- Основной экран проверен при ширине 390 px. Недельная сетка прокручивается горизонтально, карточки подходят для телефона.
- Живой ответ Gemini на вымышленное текстовое задание подтверждён отдельно, см. ai-diagnosis-2026-09-29.md. Автоматические тесты не измеряют точность модели.

## Источник расписания

`data/isr242_2026-09-28.csv`: 23 занятия на 28 сентября — 3 октября 2026. Даты, предметы, время, аудитории и читаемые части имён перенесены вручную из двух пользовательских скриншотов timetable.kgu.kz. Группа ИСР-242уск названа пользователем. Нечитаемые отчества не дополнены догадками. В субботу на снимке занятий нет. Снимок не подтверждает будущие замены и не должен повторяться еженедельно.

Расписания других групп на сайте университета требуют авторизации. До получения разрешённого источника можно импортировать свой CSV, но нельзя выдавать демо-данные за реальные.

## Границы готовности

Версия пригодна для демонстрации и ограниченного добровольного пилота. Аккаунты, облачная синхронизация, автоматические замены, push-уведомления, оценки из Platonus не входят в этот MVP. Бесплатная квота и доступность Gemini зависят от провайдера. При отказе ИИ задания вводятся вручную.

Реальные участники, точность ИИ на выборке и экономия времени пока не измерены. Поэтому «100% готовности продукта» не является проверенным показателем. Завершение программной функции и подтверждение её пользы — разные критерии.
